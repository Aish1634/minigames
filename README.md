# Memory Card Game

## Description
An interactive web-based memory card game where players match identical cards to win. The game is designed with simple logic and engaging UI for a smooth user experience.

## Features
- Card matching functionality
- Interactive gameplay
- Responsive design

## Tech Stack
- HTML
- CSS
- JavaScript
